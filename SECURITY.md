# Security Policy

## Supported Versions

NexoraDB is currently in its initial alpha stage. Security updates are provided only for the latest published release.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅ |
| < 0.1   | ❌ |

The initial binary release supports CPython 3.10 on Ubuntu 22.04 or newer, x86_64 only.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature:

1. Open the NexoraDB repository.
2. Go to **Security**.
3. Select **Advisories**.
4. Select **Report a vulnerability**.

Please include:

- A description of the vulnerability and its potential impact
- Affected NexoraDB version
- Reproduction steps or a proof of concept
- Operating system and Python version
- Any suggested mitigation, if available

You can expect an initial response within 7 days. Confirmed vulnerabilities will be investigated privately. We will coordinate disclosure and release a security update when appropriate.

Please allow sufficient time for a fix before publicly disclosing the vulnerability.
