# NexoraDB v0.2.1

NexoraDB 0.2.1 is a security maintenance release following v0.2.0.

## Security

- Updated the transitive frontend dependency `browserslist` from 4.28.4 to
  4.28.9 through the npm lockfile.
- Fixes the uncaught-crash/prototype-write issue in custom
  `browserslist-stats.json` processing (GHSA-73wf-gq98-2v4g).
- Fixes unbounded cache growth from distinct Browserslist queries
  (GHSA-c83g-rgw3-j3cx).

## Verification

- `npm audit`: 0 vulnerabilities.
- Frontend production build: passed.
- ESLint: passed.
- Resolved dependency: `browserslist@4.28.9`.

All database engine, index, transaction, query planner, pagination, benchmark,
and Python packaging improvements from v0.2.0 are included unchanged.

## Installation

```bash
pip install NexoraDataBase==0.2.1
```
